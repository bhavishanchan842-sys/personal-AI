3. Gaps in Existing Systems

1. Property-Centric vs Human-Centric

Existing portals treat room hunting strictly as real estate. In shared living, tenant satisfaction is 80% determined by roommate interpersonal harmony.

2. The 'Blind Booking' Risk

Students sign leases without knowing if current roommates are night owls, strict non-veg, or have incompatible hygiene standards, causing rapid disputes.

3. Missing Indian PG Context

Global platforms fail to support Boys/Girls/Co-Ed PGs, Food/Mess inclusions (3 meals/day), Curfew rules, and Zero Brokerage verification.

4. Absence of Dispute Prevention Tools

No platforms provide objective tools like Fair Rent Splitters (adjusting rent for attached bathrooms/balconies) or digital co-living agreements.

4. Problem Statement

FORMAL PROBLEM STATEMENT

"To design and develop an intelligent web platform that bridges the gap between student/PG accommodation discovery and algorithmic roommate lifestyle compatibility, enabling seekers to evaluate physical property attributes and occupant compatibility simultaneously before committing to financial deposits or residential agreements."

Target Demographics

  • • Undergraduate and postgraduate university students.
  • • Entry-level IT and corporate professionals moving to tech clusters.
  • • Independent PG owners seeking long-term, harmonious tenants.

Key Pain Points Addressed

  • ✓ Eliminates the financial risk of incompatible co-living.
  • ✓ Real-time visibility into existing flatmates' daily habits.
  • ✓ Transparent, zero-brokerage room search.

5. Project Objectives

Primary Objectives

  • 🎯 PG Discovery Hub: Build multi-attribute filters (Boys/Girls/Co-Ed PGs, single/sharing rooms, 3 meals included, zero brokerage).
  • 🎯 Algorithmic Compatibility Engine: Calculate match scores (0–100%) using weighted Euclidean vector distance across 6 lifestyle dimensions.
  • 🎯 Dual-Integration Architecture: Display live roommate compatibility scores directly on room listings cards.
  • 🎯 Visual Radar Comparison: Render 6-axis Radar charts with Green Flags (strengths) and Yellow Flags (habits to discuss).

Secondary / Utility Objectives

  • ⚡ Dealbreaker Filtering: Enforce hard constraints for smoking, alcohol, pets, and dietary conflicts (Pure Veg vs Non-Veg).
  • ⚡ Fair Rent Splitter: Algorithmic tool dividing rent fairly based on room size, attached washroom, and balcony.
  • ⚡ Digital Roommate Agreement: 11-Month standardized house rule and chore contract generator.
  • ⚡ Modern SPA Performance: Responsive, high-speed user experience with React 18, Vite, and Python FastAPI.
