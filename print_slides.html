3. Gaps in Existing Systems

1. Property-Centric vs Human-Centric

Existing portals treat room hunting strictly as real estate. In shared living, tenant satisfaction is 80% determined by roommate interpersonal harmony rather than wall paint or floor tiles.

2. The 'Blind Booking' Risk

Tenants sign leases without knowing if current occupants are night owls, non-vegetarians, smokers, or have incompatible hygiene habits, causing immediate conflict and lease breaks.

3. Missing Indian PG Context

Global platforms fail to support Indian realities: Boys/Girls/Co-Ed PGs, Food/Mess inclusions (3 meals/day vs self-cooking), Curfew rules, and Zero Brokerage verification.

4. Absence of Dispute Prevention Tools

No existing platforms provide objective tools like Fair Rent Splitters (adjusting rent for attached bathrooms/balconies) or structured digital co-living agreements.

SLIDE 5/5

5. Project Objectives

Primary Objectives

  • 🎯 Interactive PG & Room Discovery Engine: Develop filters for Boys/Girls/Co-Ed PGs, single/sharing occupancy, 3 meals included, and budget in ₹ INR.
  • 🎯 Algorithmic Compatibility Engine: Implement weighted Euclidean vector distance math across 6 lifestyle dimensions (Sleep, Cleanliness, Social, Work, Noise, Cooking).
  • 🎯 Dual-Integration Architecture: Embed real-time occupant compatibility match % directly into property listing cards.
  • 🎯 Visual Radar Comparison: Generate 6-axis Radar charts with automatic Green Flags (strengths) and Yellow Flags (habits to discuss).

Secondary / Utility Objectives

  • ⚡ Dealbreaker Enforcement: Enforce strict rules for smoking, alcohol, pets, and dietary preferences (Pure Veg vs Non-Veg).
  • ⚡ Mathematical Fair Rent Splitter: Build an objective calculator dividing rent based on room size, attached washroom, and balcony.
  • ⚡ Digital Roommate Agreement: Standardize house rules, quiet hours, and chore rotation contracts with print/export options.
  • ⚡ High-Performance Architecture: Provide a fast, responsive Single Page Application (SPA) using React 18, Vite, and Python FastAPI.
